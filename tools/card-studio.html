使い方
1. 上のURLを GitHub Pages の公開URLに書き換える
2. ①②③ をこの順に押してダウンロード
3. card-marker.png と targets.mind をリポジトリの assets/ に置く
4. card-print.png を名刺印刷に入稿

AR認識を安定させるコツ
・白ベタの余白を減らし、非対称な模様を入れる（パターン量を10以上に）
・QRコードだけだと似た模様の繰り返しで弱いので、模様＋文字＋QRの組み合わせが効く
・つや消し（マット）紙で印刷する。光沢紙は反射でトラッキングが飛びやすい
・デザインを変えたら必ず ①→② をやり直す（画像と .mind は必ずペア）
